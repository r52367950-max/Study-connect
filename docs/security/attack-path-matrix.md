# 攻击路径矩阵（组合利用回归）

> 目标：验证单点修补后，是否存在跨模块联动绕过。

## 1) 跨站请求 + Cookie 会话

| 项目 | 内容 |
| --- | --- |
| 攻击前提 | 攻击者可诱导用户发起跨站请求，且用户浏览器已持有会话 Cookie。 |
| 触发条件 | 1）会话 Cookie 未设置安全属性；2）鉴权端点仅依赖 Cookie 且缺少角色隔离。 |
| 预期拦截点 | `HttpOnly + SameSite` Cookie；`/admin/**` 路由角色鉴权。 |
| 日志特征 | 连续 `401/403`，来源角色与请求路径不匹配。 |
| 对应用例 | `npm run test:min-auth`、`npm run test:min-auth-abuse-chain` |

## 2) 爆破 + 弱口令 + 接口滥用

| 项目 | 内容 |
| --- | --- |
| 攻击前提 | 已知有效账号邮箱，尝试弱口令注册和重复撞库登录。 |
| 触发条件 | 1）弱口令校验缺失；2）多次错误登录后仍可越权调用管理接口。 |
| 预期拦截点 | 注册参数校验（弱口令拒绝）；错误密码 `401`；普通用户访问管理接口 `403`。 |
| 日志特征 | 同账号短时间高频 `401`，并伴随 `403` 的越权探测。 |
| 对应用例 | `npm run test:min-auth-abuse-chain` |

## 3) 上传伪装 + 下载链路触达

| 项目 | 内容 |
| --- | --- |
| 攻击前提 | 攻击者拥有普通用户账号，尝试上传伪装文件并沿下载链路触达存储对象。 |
| 触发条件 | 1）MIME 白名单失效；2）超大文件绕过限制；3）未审批资源可下载。 |
| 预期拦截点 | 上传文件类型校验 `422`；体积边界校验 `422`；未授权/未审批下载被拒绝。 |
| 日志特征 | `422` 上传拒绝、`401/404` 下载拒绝，并且仅存在合法上传对象落库。 |
| 对应用例 | `npm run test:min-material-upload`、`npm run test:min-material-download` |

## 4) 错误分流 + 资源探测

| 项目 | 内容 |
| --- | --- |
| 攻击前提 | 攻击者通过非法分页参数或未知路径探测系统内部资源。 |
| 触发条件 | 1）参数边界校验缺失；2）错误响应泄露实现细节。 |
| 预期拦截点 | DTO 边界校验 `400`；未知路径 `404` 且不暴露内部组件信息。 |
| 日志特征 | 持续异常参数请求触发 `400/404`，无堆栈/组件名外泄。 |
| 对应用例 | `npm run test:min-auth-abuse-chain`、`npm run test:min-admin-update-review-errors` |

## CI 门禁策略

- 回归套件脚本：`npm run test:security-attack-chain`
- 门禁策略：任一组合攻击链用例失败，CI 直接失败并阻断合并。
- 发布要求：禁止“先合并后补测”。
